1. 服务介绍

SeeZn ID（以下简称“本服务”）是由 SeeZn 运营的统一身份认证与账户管理服务。本服务通过 Keycloak 身份认证基础设施，为 SeeZn 旗下及经授权接入的应用程序提供统一的身份认证能力。

主要功能包括：

  • 用户账户注册与登录。
  • 用户身份验证及会话管理。
  • Google 等第三方身份提供商登录。
  • 账户资料管理。
  • 用户身份与第三方账户关联。
  • 向授权接入应用提供必要的身份信息。
  • 账户安全保护及异常登录检测。
  • 用户账户注销及个人信息管理。

本服务的核心用途是为用户提供统一、安全的身份认证体验，而不是收集与身份认证无关的个人数据。

2. 适用范围

本条款适用于：

  1. 访问 SeeZn ID 官方网站的用户。
  2. 注册或使用 SeeZn ID 账户的用户。
  3. 使用 Google 或其他第三方账户登录的用户。
  4. 使用 SeeZn ID 登录授权接入应用的用户。
  5. 使用 SeeZn ID 提供的其他身份认证功能的用户。

通过 SeeZn ID 登录的第三方应用可能拥有自己的服务条款和隐私政策。使用第三方应用时，用户还应阅读该应用单独公布的相关政策。

3. 账户注册

用户可以通过本服务支持的方式创建账户，包括：

  • 电子邮箱注册。
  • 用户名和密码注册。
  • Google OAuth 登录。
  • 其他经本服务正式支持的身份认证方式。

用户应当：

  • 确保注册邮箱可以正常接收邮件。
  • 妥善保管账户密码和其他认证凭据。
  • 不得冒用其他个人或组织的身份。
  • 不得通过自动化方式恶意创建大量账户。

用户应对自己账户下的操作负责，但因本服务安全漏洞或其他依法应由服务运营方承担的原因造成的损失，不受本条款不合理免责内容的影响。

4. 第三方身份认证

SeeZn ID 支持通过第三方身份提供商进行认证。例如 Google 登录可能使用：

  • OpenID Connect。
  • OAuth 2.0 Authorization Code Flow。
  • Google 提供的账户身份信息。

使用 Google 登录时，用户可能被要求授权以下基本身份信息：

  • openid：验证用户身份及获取唯一账户标识。
  • email：获取电子邮箱地址及验证状态。
  • profile：获取基本个人资料，例如姓名和头像。

实际请求范围以 Google Cloud Console 和实际运行的认证客户端配置为准。

SeeZn ID 不会将 Google 登录授权解释为用户允许访问其所有 Google 服务或账户内容。未经用户单独授权，本服务不会主动请求与当前身份认证功能无关的 Google API 权限。

第三方身份提供商的服务受其各自服务条款和隐私政策约束。Google 服务条款：https://policies.google.com/terms；Google 隐私政策：https://policies.google.com/privacy。

5. 用户授权与应用接入

SeeZn ID 允许经过配置和授权的应用接入统一身份认证系统。在用户主动选择某个应用并完成身份认证后，本服务可以按照该应用的授权配置向其提供必要的身份信息，可能包括：

  • 用户唯一标识符。
  • 用户名。
  • 电子邮箱地址。
  • 邮箱验证状态。
  • 显示名称。
  • 头像信息。
  • 应用完成认证所需的其他基本资料。

具体信息取决于应用的客户端配置、授权范围及用户同意情况。本服务不会因为用户登录一个接入应用，就自动向该应用开放用户的全部个人资料。接入应用应当仅将获得的信息用于其向用户展示的功能，并遵守适用的数据保护要求。
