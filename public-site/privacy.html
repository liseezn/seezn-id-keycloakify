隐私政策

生效日期：2026年11月21日　最后更新：2026年11月21日

本隐私政策说明我们如何处理您的个人信息，其中第 4 章专门说明 Google 用户数据。

核心承诺：我们只处理提供身份认证、账户管理和服务安全所必需的信息；不出售您的个人信息；不将 Google 用户数据用于广告或与身份认证无关的用途。

1. 引言

SeeZn ID（以下简称“SeeZn ID”“我们”或“本服务”）重视用户的隐私和个人信息保护。本隐私政策说明我们在用户访问官方网站、创建账户、登录、使用统一身份认证以及通过第三方身份提供商完成身份验证时，如何收集、使用、存储、共享、保护和删除个人信息。

SeeZn ID 是一个统一身份认证与账户管理服务，使用部署于 https://auth.liseezn.top 的 Keycloak 身份认证基础设施，可能为 SeeZn 旗下应用及经授权接入的第三方应用提供身份验证能力。

我们遵循以下原则：

  1. 仅处理提供身份认证服务所必要的信息。
  2. 仅在明确目的和合法依据范围内使用个人信息。
  3. 不出售用户个人信息。
  4. 不将 Google 用户数据用于广告定向或广告画像。
  5. 不向未经授权的应用开放用户身份信息。
  6. 采取合理措施保护个人信息。
  7. 为用户提供查询、更正、撤销授权和删除数据的途径。

3. 我们收集的信息

我们按照用户使用的功能和授权情况处理以下类别的信息。

3.1 账户注册信息

当用户创建 SeeZn ID 账户时，可能处理：

  • 用户唯一标识符。
  • 用户名。
  • 电子邮箱地址。
  • 密码验证信息（以安全的密码哈希保存，而非明文）。
  • 账户创建时间。
  • 账户状态。
  • 邮箱验证状态。

具体账户字段取决于实际 Keycloak 用户配置。

3.2 第三方登录信息

当用户使用 Google 或其他第三方身份提供商登录时，我们可能接收：

  • 第三方提供商名称。
  • 第三方账户唯一标识符。
  • 电子邮箱地址。
  • 邮箱验证状态。
  • 姓名或显示名称。
  • 头像地址。
  • 身份认证结果。
  • 用户授权和账户关联状态。

这些信息用于识别用户、创建账户、关联已有账户以及完成登录。我们不会将第三方登录解释为用户授权我们访问其全部第三方账户数据。

3.3 认证与会话信息

为了提供安全的登录功能，我们可能处理：

  • 会话标识符。
  • 登录状态。
  • 登录时间。
  • 会话创建及过期时间。
  • 认证结果。
  • 登录失败记录。
  • 设备和浏览器基本信息。
  • 必要的安全事件记录。

会话信息用于维持用户登录状态、防止会话滥用及保护账户安全。

3.4 技术与安全信息

在用户访问服务时，服务器可能自动记录：

  • IP 地址。
  • 请求时间。
  • 请求路径。
  • HTTP 状态码。
  • 浏览器类型。
  • 操作系统信息。
  • 错误日志。
  • 安全防护日志。
  • 访问频率及异常请求信息。

这些信息用于排查系统错误、防止恶意访问、调查安全事件、保障服务稳定和维护服务器运行。我们不会将这些技术信息无限制地用于与服务无关的用户画像或广告目的。

3.5 用户主动提交的信息

用户主动联系我们、提交反馈或申请账户删除时，我们可能处理：

  • 联系邮箱。
  • 申请内容。
  • 账户标识。
  • 与申请处理有关的通信记录。

我们只在处理对应请求所需的范围内使用这些信息。

4. Google OAuth 数据处理政策

本章节专门说明 SeeZn ID 对 Google 用户数据的处理方式。

4.1 Google 数据获取方式

当用户选择使用 Google 登录时，SeeZn ID 会通过 Google 提供的 OAuth 2.0 / OpenID Connect 授权流程完成身份验证，用户需要在 Google 授权界面确认相关授权。对于基本身份认证，可能使用以下权限：

Scope数据用途
openidGoogle 唯一用户标识验证身份、关联账户
email电子邮箱地址及验证状态创建账户、识别用户
profile姓名、头像等基本资料展示账户信息

实际请求的 Scope 以生产环境 OAuth 客户端配置为准。如果未来新增 Google API 权限，我们会在上线前重新评估其必要性，并在适用情况下更新隐私披露及取得必要授权。

4.2 Google 数据的具体使用目的

我们仅将通过基本身份认证获得的 Google 数据用于：

  1. 确认用户的 Google 账户身份。
  2. 获取 Google 账户的唯一身份标识。
  3. 创建或关联 SeeZn ID 账户。
  4. 获取用户授权提供的邮箱信息。
  5. 根据用户授权显示姓名或头像。
  6. 维护登录状态。
  7. 保障认证过程安全。
  8. 处理用户提出的账户管理请求。

Google 数据不会被用于与上述身份认证功能无关的目的。我们不使用 Google API 或 Google 用户数据来生成、处理或传播任何图像或生成式 AI 内容。

4.3 Google 数据的存储

在身份认证和账户管理确有必要时，我们可能将必要的 Google 用户信息保存在 SeeZn ID 账户数据库中，例如：

  • Google 唯一账户标识。
  • 电子邮箱地址。
  • 邮箱验证状态。
  • 显示名称。
  • 头像地址。
  • 身份提供商及账户关联信息。

数据保存的实际字段取决于 Keycloak 用户存储配置、身份提供商映射及账户管理功能。如果认证流程产生访问令牌、刷新令牌或其他凭据，我们将根据实际认证配置决定是否保存；不再需要的授权凭据应按照实际令牌生命周期和撤销机制处理。我们不会为了与身份认证无关的目的无限期保留 Google 数据。

4.4 Google 数据的共享

在用户使用 SeeZn ID 登录授权接入应用时，我们可能根据实际授权配置向对应应用提供完成身份认证所必要的资料，包括用户唯一标识符、用户名、电子邮箱地址、邮箱验证状态、显示名称和头像信息。具体数据取决于 OAuth Client、OIDC Claims、协议映射及用户授权。我们不会默认向所有接入应用共享用户的全部身份信息。

除以下合法且必要的情况外，我们不会向其他第三方披露 Google 用户数据：

  • 为完成用户明确请求的身份认证功能，按照授权范围向对应接入应用提供必要数据。
  • 为维护系统安全、防止欺诈或调查安全事件。
  • 为遵守适用法律、法规或有效法律程序。
  • 在法律允许的情况下，经用户明确同意进行必要的数据处理或披露。

对于云服务器、数据库托管、网络防护等基础设施服务提供商，仅在提供服务所必需的范围内处理相关数据，并通过适当措施限制其访问。我们不会出售 Google 用户数据，也不会将 Google 用户数据提供给广告平台、数据经纪商或信息转售商。

4.5 Google API 有限使用声明（Limited Use）

SeeZn ID 对从 Google API 接收的信息的使用及向任何其他应用的传输，遵循 Google API 服务用户数据政策，包括有限使用（Limited Use）要求。

我们承诺：

  2. 不出售 Google 用户数据。
  3. 不将 Google 用户数据用于广告投放。
  4. 不使用 Google 用户数据进行个性化广告、兴趣广告或广告再营销。
  5. 不将 Google 用户数据用于与身份认证无关的用户画像。
  6. 不允许员工、承包商或其他人员随意访问 Google 用户数据。

  9. 不允许服务提供商将 Google 用户数据用于其自身无关目的。
  10. 在用户撤销授权或申请删除数据时，按照实际情况和适用法律处理相关数据。

Google API 服务用户数据政策：https://developers.google.com/terms/api-services-user-data-policy

4.6 Google 授权撤销

用户可以通过 Google 账户的第三方应用授权管理页面撤销 SeeZn ID 的 Google 授权：https://myaccount.google.com/connections。撤销授权可能导致：

  • 无法继续通过该 Google 账户完成新的授权登录。
  • 需要重新授权才能继续使用相关功能。
  • 已建立的 Google 账户关联需要重新处理。

撤销 Google 授权与删除 SeeZn ID 账户是两个不同的操作。如果用户还希望删除 SeeZn ID 中保存的个人信息，应另外提交账户删除申请。

9. 数据安全保护

我们采取合理的技术和组织措施，保护个人信息免受未经授权的访问、披露、修改、丢失或破坏。安全措施可能包括：

  • 使用 HTTPS。
  • 使用 TLS 加密网络通信。
  • 限制不安全的认证回调地址。
  • 防止认证令牌通过不安全渠道传输。

9.2 账户安全

  • 安全密码哈希。
  • 身份验证及访问权限控制。
  • 会话有效期管理。
  • 登录异常监测。
  • 必要的身份验证措施。

9.3 系统安全

  • 服务器访问权限控制。
  • 数据库访问控制。
  • 认证配置保护。
  • 反向代理安全配置。
  • 网络攻击防护。
  • 系统更新与漏洞修复。
  • 必要的安全日志记录。

9.4 管理安全

  • 限制能够访问用户数据的人员。
  • 仅允许经过授权的管理人员访问必要信息。
  • 对安全事件进行调查。
  • 按照适用法律处理数据安全事件。

尽管我们采取合理的安全措施，但任何互联网服务都无法保证绝对安全。

11. 账户注销和数据删除流程

用户可以通过以下方式申请注销账户或删除个人信息：

  1. 访问 SeeZn ID 官方网站。
  2. 发送邮件至 mail@liseezn.top 提交账户删除请求。
  3. 提供必要的账户识别信息。
  4. 按要求完成身份验证。
  5. 等待申请处理（核实后 30 天内，法律另有规定的除外）。
  6. 收到账户注销或删除处理结果。

申请时建议提供 SeeZn ID 用户名或账户标识、注册邮箱以及删除请求说明。请勿在普通邮件中提交密码、访问令牌或其他敏感认证凭据。

删除处理范围

经核实后，我们将按照适用法律和实际数据存储情况处理：

  • SeeZn ID 账户资料。
  • Google 账户关联信息。
  • 用户基本个人资料。
  • 不再需要的身份认证数据。
  • 与账户有关的必要会话及授权信息。

以下信息可能在必要范围内继续保存：

  • 法律要求保存的数据。
  • 与正在处理的法律争议有关的数据。
  • 防止欺诈和处理安全事件所必需的数据。
  • 其他具有合法保存依据的信息。

继续保存的数据将限制访问，并在保存依据消失后按照适用要求处理。

第三方应用数据
